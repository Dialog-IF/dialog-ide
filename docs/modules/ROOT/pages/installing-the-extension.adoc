it is active._

== Installing from the Extensions view

* Open the Extensions view (`Cmd/Ctrl+Shift+X`), search *Dialog IDE*, click *Install*.
* Publisher is `hlship`; the Marketplace id is `hlship.dialog-ide`.
* You may see a note that the publisher is *not verified* (wording is roughly "hlship is not a
  verified publisher" / "This publisher has not verified ownership of a domain"). That is only about
  domain verification, which Dialog IDE has not set up — it is expected, not a security warning.
  Proceed with the install.

== Other ways to install

* Command line: `code --install-extension hlship.dialog-ide`.
* From a `.vsix` file (offline machines, or a pre-release build): Extensions view *"..."* menu >
  *Install from VSIX...*, or `code --install-extension dialog-ide-<version>.vsix`.

== What the Dialog toolchain needs on your platform

The extension drives external binaries (`dgdebug`, `dialogc`, and — for some features — `aambundle`
and `dfrotz`). Whether you need to install those yourself depends on your platform.

== The dialog-language-support conflict

* If you previously installed the separate
  https://marketplace.visualstudio.com/items?itemName=sideburns3000.dialog-language-support[`dialog-language-support`]
  extension, Dialog IDE warns once at startup and offers to help you disable or uninstall it.
* Running both causes inconsistent `.dg` highlighting and a duplicate "Compile to..." context-menu
  entry. Pick one; Dialog IDE now bundles the same grammar.

== Confirming it is active

* Open any `.dg` file — you should get syntax coloring, and an Outline view
  (`Cmd/Ctrl+Shift+O` for the in-file symbol jump).
* A Skein status-bar item appears at the bottom-left: *$(play) Dialog Skein* when idle.
